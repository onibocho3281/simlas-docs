# Simlas

Welcome to the public documentation for **Simlas**, a Discord companion for *The Witcher TRPG*.

Simlas helps a table use character data, rolls, turns, combat, equipment, conditions, and other game-state tools directly in Discord while C.O.D.I. remains the source for calculated player-character values.

Simlas is currently in active development and is being tested with invited users.

## Guides

### Player Guide

The [Player Guide](PLAYER_GUIDE.md) explains how to:

- join a game;
- link and use a C.O.D.I. character;
- make rolls;
- manage weapons and carried equipment;
- use turn actions;
- attack and defend;
- resolve damage;
- work with conditions and Critical Wounds;
- use special combat actions;
- troubleshoot common problems.
